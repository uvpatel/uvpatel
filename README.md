### AI-Powered Network Intrusion Detection System

A cybersecurity ML system developed during my internship using the UNSW-NB15 dataset.

- Trained and compared Decision Tree, Random Forest, Extra Trees, Naive Bayes, KNN, SVM, and XGBoost models
- Supports binary intrusion detection and multiclass attack classification
- Includes preprocessing, feature selection, model persistence, and an interactive Streamlit dashboard
- Achieved approximately **90% binary classification accuracy** with the strongest models

**Technologies:** Python, Pandas, scikit-learn, XGBoost, Streamlit, Matplotlib, Seaborn
